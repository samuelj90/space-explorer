✨ Cross-Platform Disk Analyzer & Cleaner

Reclaim Gigabytes of Wasted Disk Space

Space Explorer inspects developer projects for expendable build artifacts and cleans system package caches with single-click safety.

⬇️ Download Windows App (.exe) ⭐ View on GitHub

Engineered for Developers

Built with zero runtime bloat, zero dependencies, and cross-platform flexibility.

📁

Project Artifact Detection

Recursively locates heavy expendable artifacts without touching source code:

node_modules target .venv .next build dist

📦

Package & System Caches

Reclaims massive hidden disk caches from package managers across macOS, Windows, and Linux:

npm yarn pip cargo homebrew gradle

⚙️

Configurable Rules

Add, customize, and manage artifact detection rules directly from the web or desktop UI. Custom rules automatically persist to ~/.space-explorer-rules.json.

🛡️

Safe Deletion & Trash Undo

Supports moving deleted artifacts directly to your system Trash for instant recovery, accompanied by strict path guardrails that prevent accidental project deletion.

💻

Desktop & Web Modes

Run as a standalone desktop application via Electron or launch the lightweight embedded web server in your favorite browser.

⚡

Command Line Interface

Automate scans and dry-run cleanup pipelines in terminal or CI environments using single-responsibility Python CLI tools.

Quick Start

Run Space Explorer locally in seconds.

macOS / Linux
# Clone and start
git clone https://github.com/samuelj90/space-explorer.git
cd space-explorer
./run.sh
Windows
# Run from cmd/powershell
git clone https://github.com/samuelj90/space-explorer.git
cd space-explorer
run.bat
Desktop (Electron)
# Launch desktop app
npm install
npm start

# Or build Windows installer
npm run build:win
